#########################################

What Claude Code Is

Claude Code is an agentic coding assistant that runs in your terminal. Unlike a chat interface, it
has direct access to your filesystem — it can read files, write files, run commands, and iterate on
code without copy-pasting. For building a multi-module trading bot, this makes it dramatically
faster than a standard IDE workflow.

Claude Code excels at:
• Scaffolding new modules from a description of what they should do
• Debugging by reading your traceback and the relevant source file together
• Iterative development — you build one module, test it, then say "now add X feature"
• Connecting modules — once you have weather.py and polymarket.py, you can say "build edge.py that calls both of these"

#########################################

Handling Claude Code Errors
When code fails, paste the full traceback into the session:

"This error occurred when running edge.py:
[paste full traceback here]
Here is the current content of edge.py:
[paste file content or use /add edge.py]
Fix the error."

Claude Code works best when it has both the error message AND the source file.

#########################################

What to Put in CLAUDE.md

CLAUDE.md is a plain text file that Claude Code reads at the start of every session. It acts as
persistent context so you don't have to re-explain the project each time. See Section 12 for a
complete filled-out example.

    Label	                                   Plain English	                                                          Source

Historical Avg	    The 10-year average temperature for this same calendar date and location	    ERA5 reanalysis data, used as a Bayesian anchor at longer forecast horizons (>7 days)
